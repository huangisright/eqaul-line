# 可及性分析工具 — 學生使用指南

這套工具可以分析「從某種設施出發，走路（或騎車、開車）N 分鐘能到哪裡」，並算出覆蓋面積、覆蓋率、服務到多少人。原型來自「請再給我一間便利商店吧——找出金門便利商店最佳拓點」科展作品，現在你可以用它分析**自己的家鄉、任何設施**。

## 一、事前準備（約 10 分鐘）

1. 電腦安裝 Python 3（python.org 下載，安裝時勾選 Add to PATH）。
2. 到 https://openrouteservice.org 免費註冊，登入後在 Dashboard 建立一把 API Key。免費額度：等時線每天 500 次、每分鐘 20 次，做研究綽綽有餘。
3. **金鑰是個人的，不要貼到網路上、不要放進 git。**

## 二、設定你的研究題目

打開 `config.json`，只需要改三個地方：

1. `area.admin_name`：改成你要研究的行政區，例如 `"澎湖縣"`、`"臺東市"`。名稱要和 OpenStreetMap 上一致，可先到 openstreetmap.org 搜尋確認。
2. `poi_groups`：改成你要研究的設施。`overpass_filter` 是 OSM 標籤條件，範例：
   - 藥局：`"[\"amenity\"=\"pharmacy\"]"`
   - 國小：`"[\"amenity\"=\"school\"]"`
   - 消防隊：`"[\"amenity\"=\"fire_station\"]"`
   - 公車站：`"[\"highway\"=\"bus_stop\"]"`
   （可到 overpass-turbo.eu 先測試條件抓不抓得到東西）
3. `ors_api_key`：貼上你的金鑰。

`profiles`（步行/自行車/開車）和 `ranges_minutes`（幾分鐘）也可以調，但組合越多、API 請求越多，跑得越久。

## 三、執行

在 toolkit 資料夾打開終端機：

    python pipeline.py

會依序：抓設施座標 → 抓行政區邊界 → 預計算等時線 → 產出網頁資料。中途斷線沒關係，再跑一次會從快取接著跑。完成後用瀏覽器打開 `site/index.html`。

## 四、網頁操作

選擇設施、交通方式、時間，按「更新地圖」，就會看到等時線覆蓋範圍與統計（覆蓋面積、覆蓋率、加權人口——人口需在 config 提供村里資料才會顯示）。

勾選「候選點模式」並貼上你的金鑰後，**點地圖上任何位置**，就會即時算出：如果在這裡新設一個據點，能「新增」多少覆蓋面積與服務人口（紅色區塊）。這就是找最佳拓點的核心操作。

## 五、可以討論的研究問題（題庫）

### 民生商業
- 哪個村里走路 15 分鐘內完全沒有任何便利商店／藥局？那裡住了多少人？
- 用候選點模式測 5 個地點，哪一個「新增服務人口」最多？為什麼？
- 兩家超商品牌的展店策略有何不同？誰的覆蓋重疊率高、誰在搶未開發區？

### 緊急救援（設 `profiles` 為 `driving-car`，`ranges_minutes` 改 4、6、8 分鐘）
- 消防隊：`"[\"amenity\"=\"fire_station\"]"`。消防車出勤的黃金時間約 6～8 分鐘，哪些村落在 8 分鐘圈外？住了多少人？用候選點模式找出「新增涵蓋人口最多」的新分隊位置。
- 救護與 AED：`"[\"emergency\"=\"ambulance_station\"]"`、`"[\"emergency\"=\"defibrillator\"]"`。心臟停止後每分鐘存活率降約 10%，步行 3 分鐘內拿得到 AED 的區域有多大？
- 注意：本工具算的是「一般小客車」時間，消防車實際會更快（可闖紅燈）或更慢（大型車輛），報告中要說明這個誤差方向。

### 大眾運輸
- 公車站牌：`"[\"highway\"=\"bus_stop\"]"`，步行 10 分鐘。全區有多少比例的人口在「步行可達公車站」範圍內？哪些聚落是完全搭不到公車的「運輸孤島」？
- 進階：站牌可達 ≠ 有用——把 filter 換成只有特定路線停靠的站，或比較「站牌 500 公尺圓圈」與「步行 6 分鐘等時線」在有河、大馬路阻隔處的差異。

### 醫療與高齡照護
- 衛生所／診所：`"[\"amenity\"~\"clinic|doctors\"]"`。把各村里的「老年人口比例」和「醫療設施步行可達性」放在一起看，最需要醫療的地方反而最難到達嗎？
- 老人步行速度較慢：把時間門檻打 7 折（15 分鐘當 10 分鐘用）重算，覆蓋人口掉多少？

### 教育
- 國小通學圈：`"[\"amenity\"=\"school\"]"`，步行 10～15 分鐘。哪些聚落的孩子走路上不了學？若某分校裁併，受影響學區的通學時間增加多少？

### 防災
- 避難收容所（需自備座標清單，直接編輯 data/pois.json）：颱風或空襲情境下，步行 10 分鐘內到不了任何收容所的人口有多少？

### 方法與批判思考
- 步行 vs 開車的覆蓋結果差多少？這對沒有汽車的老人代表什麼？
- 等時線（沿真實道路）和直線半徑畫圓的結果差在哪？找一個差異最大的例子解釋原因。
- OSM 資料不完整怎麼辦？實地查訪你家附近，數一數 OSM 漏了幾個站牌／AED，估計漏登率對結論的影響。
- 同一題目跑兩個離島（金門 vs 澎湖），只改 config 的 admin_name，比較誰的服務缺口大。

## 六、常見問題

- **抓不到設施**：先到 overpass-turbo.eu 測試你的 filter；OSM 上該地區可能根本沒人標注這種設施（這本身也是發現！）。
- **API 回 403/429**：金鑰打錯或超過每日額度，隔天再跑（快取會保留進度）。
- **人口統計不顯示**：config 的 `population.geojson` 沒設或檔案格式不符。GeoJSON 每個區域要有一個數值欄位當權重（純人口數也可以）。
